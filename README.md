📊 Sales Performance Analysis & Executive Dashboard Project📌 Project OverviewThis project demonstrates an end-to-end data analytics workflow, taking a raw, unformatted sales transaction dataset and transforming it into a clean, structured asset paired with an interactive executive dashboard in Microsoft Excel.The project addresses common real-world data quality issues—such as inconsistent casing, mixed date formats, missing values, hidden whitespace, currency text symbols, and calculation errors—showcasing data wrangling, advanced formula architecture, and professional reporting design.📁 Repository Structure & Files ExplainedSales_transactions_2022_2025.csv (Raw Dataset)Contains uncleaned transactional records with deliberate real-world data anomalies designed to test and demonstrate data-cleaning proficiency.Sales (Cleaned_Data.xlsx) (Cleaned Dataset)The fully standardized, validated, and type-corrected version of the transaction records, ready for advanced analysis and reporting.Sales Analysis and Dashboard.xlsx (Dashboard & Pivot Analysis)The interactive reporting workbook featuring structured Pivot Tables, dynamic summary metrics, and executive visualizations powered by interactive Slicers.📋 Schema Breakdown Across Datasets1. Sales_transactions_2022_2025.csv (Raw Schema & Anomalies)The raw CSV file contains unformatted data with the following column structure and inherent challenges:Column NameData TypeReal-World Data Anomalies PresentOrder IDAlphanumericContains duplicate transaction entries that require deduplication.Order DateMixed Text/DateInconsistent date notations (e.g., YYYY-MM-DD, MM/DD/YYYY, DD.MM.YYYY), trailing spaces, and invalid string entries (e.g., INVALID_DATE).Product NameTextIrregular leading/trailing whitespace and inconsistent naming spacing.CategoryTextInconsistent text casing (mixed uppercase and lowercase variations).RegionTextCapitalization discrepancies and blank/missing region records (NULL).SalespersonTextHidden spaces and inconsistent capitalization across representative names.Quantity SoldMixed/NumericContains non-numeric text entries (e.g., "five"), zero values, negative numbers, and missing values.Unit PriceMixed/TextContains embedded currency text symbols ($), extra whitespace, and invalid price strings.Total SalesMixed/NumericCorrupted by calculation mismatches, error text strings (ERROR), and missing values.2. Sales (Cleaned_Data.xlsx) (Cleaned Schema & Transformations)In this workbook, the raw anomalies have been completely resolved to establish a reliable source of truth:Column NameData TypeCleaning & Standardization AppliedOrder IDTextUnique identifiers verified; exact duplicate rows purged.Order DateDate (ISO)Standardized into a uniform ISO date format (YYYY-MM-DD) for accurate time-series analysis.Product NameTextCleaned using TRIM() to eliminate rogue whitespace and normalize product titles.CategoryTextStandardized using proper casing (PROPER) across all product categories (Electronics, Furniture, Office Supplies).RegionTextStandardized region names (North, South, East, West) with missing values handled.SalespersonTextRepresentative names standardized and formatted cleanly.Quantity SoldIntegerText quantities converted to clean integers; negative numbers and blanks corrected.Unit PriceCurrency ($)Stripped of $ symbols and text errors, parsed into clean numeric decimal format.Total_SalesCurrency ($)Recalculated accurately using the formula: $\text{Quantity Sold} \times \text{Unit Price}$.3. Sales Analysis and Dashboard.xlsx (Dashboard Schema & Metrics)The dashboard and analysis workbook organizes the cleaned data into dynamic reporting views:Pivot Summary Tables: Group transactions by Category, Product Name, Region, Salesperson, and Order Month (Jan, Feb, Mar, Apr).Key Performance Indicators (KPIs): Executive cards tracking Total Revenue, Total Units Sold, and Average Order Value.Interactive Slicers: Dynamic filters allowing users to instantly slice and drill down into performance metrics by Region, Salesperson, and Category.
